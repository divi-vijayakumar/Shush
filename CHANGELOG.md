# Changelog

All notable user-facing changes to Shush are recorded here.

## 0.2.0 — 2026-07-31

- Added an authenticated `shush` CLI for Claude, Codex, and shell workflows.
- Added up to 10 isolated personal and work profiles with project bindings.
- Added account email display and account-password updates.
- Added multi-selection with bulk retire and permanent delete actions.
- Added local duplicate-name and value-fingerprint reporting.
- Restricted Secret Sweep to high-confidence provider keys and private keys.
- Suppressed previously imported and ignored scan matches.
- Added confirmed, recoverable source-file cleanup through macOS Trash.
- Consolidated profile, account, CLI, and lock controls in the sidebar menu.
- Added DMG checksum generation and public setup documentation.

## 0.1.0

- Initial local-first macOS app backed by the bundled Agent Vault service.
